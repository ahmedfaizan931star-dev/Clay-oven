# Clay Oven Chakwal, Fine Dining | Demo Website

A one-page demo website for **Clay Oven Chakwal** and its banquet hall, **Zohra Hall**, in Chakwal, Pakistan.

**Live demo:** https://clay-oven-chakwal-fine-dining.vercel.app/

> This is a design demo only. It is not the official website of Clay Oven Chakwal. Photos are samples from Unsplash.

## Features

- Mobile-first, responsive layout with a dark, warm theme
- Menu category cards (Chinese, Pakistani, Italian, Fast Food, Steaks, Pasta, Milk Shakes, Fresh Juices, Ice Cream Shakes)
- Zohra Hall section with a "Check Date on WhatsApp" button
- Google rating summary (4.2 stars, 877 reviews) linking to Google
- Contact section, Google Maps link, and a floating WhatsApp button
- SEO basics: meta tags and Restaurant JSON-LD schema

## Tech

Plain HTML, CSS and JavaScript in a single `index.html`. No frameworks, no build step.

## Run locally

Open `index.html` in any browser.

## Change images

All image URLs are in the `IMAGES` object near the bottom of `index.html`. Replace a URL to swap a photo.

## Deploy

Push to GitHub and import the repo on [Vercel](https://vercel.com). No settings needed.
